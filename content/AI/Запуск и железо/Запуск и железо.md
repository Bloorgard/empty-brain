Ссылки и назначение сервисов проверены 29 октября 2026 года. Аренда, оплата
и фактический запуск вычислений не тестировались.

## Облачные GPU

- [Vast.ai](https://vast.ai/) — площадка аренды GPU; [консоль](https://cloud.vast.ai/create)
- [RunPod](https://runpod.io/) — GPU Pods для своих окружений и Serverless для запуска обработчиков по запросу; [консоль развёртывания](https://console.runpod.io/deploy)
- [GPU DC](https://gpudc.ru/) — аренда серверов и рабочих станций с GPU
- [Lium](https://lium.io/) — аренда GPU-подов, управление через веб-интерфейс, CLI и API
- [Targon](https://targon.com/#pricing) — виртуальные машины и выделенные GPU-серверы для обучения и инференса

Graydient — готовая платформа генерации, её запись находится в [[AI платформы]].
