## Модели, датасеты и демо

- [Hugging Face](https://huggingface.co/) — хаб моделей и датасетов, Spaces для демо и приложений, сервисы инференса и обучения. У моделей разные лицензии; наличие на Hub не означает бесплатность любого запуска

## Запуск моделей через API

- [BLACKBOX](https://www.blackbox.ai/) — платформа облачного инференса; текущее назначение сайта отличается от прежней записи об ассистенте для кодинга

- [fal](https://fal.ai/) — API генеративных моделей изображений, видео, аудио и 3D; также развёртывание собственных моделей и вычислительные ресурсы
- [Replicate](https://replicate.com/) — запуск моделей через API, дообучение поддерживаемых моделей и развёртывание собственных через Cog
- [Together AI](https://www.together.ai/) — облачная платформа инференса, дообучения и GPU-вычислений; работает с открытыми моделями, но доступ к вычислениям тарифицируется
- [OpenRouter](https://openrouter.ai/) — единый API к моделям разных поставщиков, выбор и маршрутизация запросов между провайдерами

Аренда GPU — в [[Запуск и железо#Облачные GPU]]: RunPod, Vast.ai, GPU DC, Lium и Targon.

## Готовые интерфейсы и workflow

- [Scenario](https://www.scenario.com/) — создание изображений, видео, 3D и аудио; модели, workflow, агенты и API для производства контента
- [Graydient](https://graydient.ai/) — облачная генерация изображений, видео и музыки через готовые приложения и workflow
